# Pocketly

A pastel-geometric budgeting demo app built with Vue 3 + Vite. Designed as a QA automation practice target — every interactive element carries a `data-testid`.

## Stack

- Vue 3 + Pinia + Vue Router
- Vite (PWA via `vite-plugin-pwa`)
- TypeScript

## Project Setup

```sh
npm install
```

### Dev server

```sh
npm run dev
```

### Type-check, build, minify

```sh
npm run build
```

### Lint

```sh
npm run lint
```
